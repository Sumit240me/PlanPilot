# ✈️ PlanPilot – AI Powered Travel Planner

PlanPilot is an intelligent AI-powered travel planning platform that generates personalized travel itineraries based on a user's budget, interests, trip duration, travel style, and preferences. It leverages AI and real-time travel data to create optimized, flexible, and interactive travel experiences.

## 🚀 Features

- 🤖 AI-generated personalized travel itineraries
- 💰 Budget-based trip planning
- 🌍 Destination and attraction recommendations
- 🗺️ Interactive maps and route planning
- 🌦️ Real-time weather integration
- 🕒 Dynamic itinerary updates
- 🔐 Secure user authentication
- 📱 Responsive and modern UI

## 🛠️ Tech Stack

**Frontend**
- React.js

- Tailwind CSS

**Backend**
- Node.js
- Express.js

**Database**
